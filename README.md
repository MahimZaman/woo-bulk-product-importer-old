# Woo Bulk Product Importer

Imports product from a json data.

## Installation and use

Place the `woo-bulk-product-importer-old` directory in `wp-content/plugins/` and activate **Woo Bulk Product Importer** from the WordPress Plugins screen.

This repository preserves the earlier JSON importer. The included `sample-products.json` illustrates its input. Install it separately from the current Woo Bulk Product Importer.
